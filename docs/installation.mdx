# Installation

No Go required. Windows PowerShell:

```powershell
irm https://raw.githubusercontent.com/system1970/agent-webmcp/main/install.ps1 | iex
```

macOS/Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/system1970/agent-webmcp/main/install.sh | sh
```

Or with Go: `go install github.com/system1970/agent-webmcp@v0.1.0`.

Confirm with `agent-webmcp version` (expect `agent-webmcp 0.1.0`).
You need Chrome ≥149 (or Brave/Chromium ≥151-base).

## Verify end to end

```bash
agent-webmcp open https://webmcp.com --session setup-check
agent-webmcp list --session setup-check
agent-webmcp invoke surprise_me --params '{}' --json --session setup-check
agent-webmcp close --session setup-check
```

To wire it into an agent harness, follow `AGENT_SETUP.md` in the repo
(MCP bridge config plus operating rules).
